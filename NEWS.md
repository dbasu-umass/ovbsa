# ovbsa 2.0.0

## New features
* Added `baci()`, a new function for calculating Bias-Adjusted Confidence Intervals.

## Deprecated
* The following functions are now formally deprecated and will be removed in a future major release: `bsal()`, `kdkyrngpr2ncd()`, `kdkyrngtr2()`, `linvx()`, `pr2ncdbias()`, `salpr2ncd()`, `saltr2()`, and `tr2bias()`. Please transition your code to use `baci()`.

## Documentation
* Completely polished and updated the package `README` file, including corrected URL endpoints and formatted academic DOI links for easy reference.
